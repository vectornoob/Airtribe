# Setup Instructions

## 1. Install Java

Install JDK 11 or newer. Open a terminal and verify:

```bash
java -version
javac -version
```

Both commands should report a supported Java version.

## 2. Open in IntelliJ IDEA

1. Extract the `LearnTrack.zip` archive.
2. Open the extracted `LearnTrack` folder in IntelliJ IDEA.
3. Confirm that `src` is marked as a Sources Root. If not, right-click `src` and select **Mark Directory as → Sources Root**.
4. Open `src/com/airtribe/learntrack/Main.java`.
5. Run `Main.main()` using the green run icon.

The project uses standard Java source files and does not require an external library.

## 3. Compile and run from a terminal

Run these commands from the extracted `LearnTrack` project root.

### Windows PowerShell

```powershell
New-Item -ItemType Directory -Force out
javac -d out (Get-ChildItem -Recurse src -Filter *.java | ForEach-Object { $_.FullName })
java -cp out com.airtribe.learntrack.Main
```

### macOS / Linux

```bash
mkdir -p out
find src -name "*.java" -print0 | xargs -0 javac -d out
java -cp out com.airtribe.learntrack.Main
```

## 4. Use the application

At the main menu, choose:

- `1` to manage students
- `2` to manage courses
- `3` to manage enrollments
- `0` to exit

Follow the prompts and enter the requested values. IDs are generated by the application, so use the IDs displayed after creating records.

## 5. Important notes

- The application uses in-memory `ArrayList` collections. Data is lost when the program exits.
- Course duration must be a positive whole number.
- Student and course records can be deactivated. A deactivated record cannot be used for a new enrollment.
- If compilation fails, check that the JDK is installed and that package folders match the `package` declarations.
